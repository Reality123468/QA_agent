# 员工手册

## 第一章：考勤与假期

### 1.1 年假制度

公司为员工提供带薪年假。具体规定如下：

- 入职满1年但不满10年的员工，每年享有5天带薪年假
- 入职满10年但不满20年的员工，每年享有10天带薪年假
- 入职满20年的员工，每年享有15天带薪年假

年假可以累计，最多可累计至次年的3月31日。未休完的年假将自动清零，不予以补偿。

### 1.2 病假

员工因病需休息时，可申请病假。病假需提供医院出具的诊断证明。每年有12天带薪病假额度。

### 1.3 事假

事假需提前1天申请，经直属领导批准后方可休假。事假为无薪假。

## 第二章：薪酬福利

### 2.1 工资发放

每月15日为工资发放日，遇节假日顺延至下一个工作日。

### 2.2 五险一金

公司按照国家规定为员工缴纳五险一金。

## 第三章：行为规范

### 3.1 办公时间

标准办公时间为周一至周五，上午9:00至下午18:00，中午12:00-13:00为午休时间。

### 3.2 保密要求

员工需对公司商业秘密和内部信息保密，不得泄露给外部人员。
